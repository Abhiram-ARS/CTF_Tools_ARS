## 🛠️ CTF Tool Engine: Available Commands

| Command | Description | Action |
| :--- | :--- | :--- |
| **base64** | Launches the Base64 utility. | Executes the `base64_decoder.run()` function. |
| **ceaser** | Launches the Caesar Cipher utility. | Executes the `ceaserCipher.run()` function. |
| **exit** | Closes the application. | Terminates the program loop. |
| *Any other command* | Invalid choice. | Prints an error message. |
